Tie your emails to each workflow5 steps

A copied workflow can still point at the shared email templates, which would send Kate's version instead of yours. Reconnect every automation to your own copies:

  1. Copy each workflow above from Shared with Me into My Templates.
  2. Open the workflow and click into each automation.
  3. In the email step, choose the matching template from your library — same number and name.
  4. Check the trigger (status or date) is unchanged, then save.
  5. Repeat for every automation. When you're done, the automation count on each workflow should match the table above.

Quick check: the Client Relationship Workflow's 3 automations use the 3 Client Care emails (Anniversary, Birthday, Passport Expiration). The numbered Automated Emails — 11 through 17 — belong to the Booked Pre/Post Travel workflow.
